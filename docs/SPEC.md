# 仕様

- 追跡対象はISS (NORAD 25544) だけ。中国の天宮は対象外。
- API: `GET /v1/satellites/25544`（30秒周期）、`GET /v1/satellites/25544/tles`（約3時間周期）
- 初回はAPI制限を避けるため位置取得後1.6秒待ってTLEを取得する。
- TLEをsatellite.jsでSGP4伝播して、約90分前〜90分後を45秒刻みで描画。
- 地球の地表は半径1.55。高度を地球半径6371kmでスケールし、軌道とISSマーカーは地表より上に描く。
- ISS現在位置・高度・速度・緯度・経度・可視状態はAPIレスポンスを正本とする。地球儀上の秒単位の滑らかな移動のみTLEによる計算値。
- TLE取得失敗時は軌道を非表示とし、直近のAPI位置を表示する。位置取得失敗時は最後に取得した値とエラーを表示し、未取得時は未取得として表示する。
- FOCUS ISSは初期状態でオン。ISSの位置にカメラを合わせ、推定軌道に合わせて追従する。手動の地球儀操作で追従解除。AUTO ROTATEは初期オフ、オンにするとFOCUS ISSを解除する。FOCUS ISSを再度オンにするとAUTO ROTATEを解除する。
- ISSは3D球体とリングで1箇所に描画し、HTMLラベルはISSの文字のみ（重複するオレンジ色の2D点は描画しない）。地表への線と直下点は残す。
- 地球昼夜の境界は太陽位置から推定。夜側のテクスチャを使用。
- バックエンド、APIキー、データベースは不要。GitHub Pagesの静的配信のみ。
